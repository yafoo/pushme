## 1. 简介

PushMe 是一款基于 MQTT 协议的 Android 消息推送客户端。它通过 MQTT 长连接实时接收服务器推送的消息，并以通知的形式展示在手机上。

**核心特性：**
- 实时消息接收（基于 MQTT 长连接）
- 多种消息类型支持（文本、Markdown、HTML、URL、数据图表等）
- 消息分组与频道管理
- 消息插件系统（JavaScript 扩展）
- 消息转发（HTTP POST）
- 悬浮窗消息显示
- TTS 语音播报
- 重复通知提醒
- 数据仪表盘（图表展示）
- 自建 MQTT 服务器支持
- TLS/SSL 加密连接
- 多语言支持（中文/英文）

## 2. 快速开始

### 2.1 获取 Push Key

1. 打开 PushMe，点击左上角 **设置图标** 打开侧边栏
2. 展开 **"Push Key"** 区域
3. 点击 **"获取"** 按钮，确认获取
4. 获取成功后，即可使用 API 推送消息到手机

### 2.2 权限配置

为保证消息稳定接收，建议开启以下权限：
- **自启动**：允许 APP 开机自动启动
- **电池优化**：设置为"忽略"，防止系统杀后台
- **消息通知**：允许 APP 发送通知

### 2.3 推送第一条消息

通过 API 向 MQTT 服务器发送消息，消息格式为 JSON：

```json
{
  "title": "Hello PushMe",
  "content": "这是一条测试消息",
  "date": "2025-01-01 12:00:00",
  "type": "text"
}
```

## 4. 消息设置

侧边栏 → **消息设置**

### 4.1 TLS/SSL

- **选项**：开启/关闭
- **说明**：MQTT 连接的 TLS 加密开关。如连接失败，可尝试关闭 TLS
- **注意**：仅在未启用自建服务时显示此选项

### 4.2 自建服务

点击 **"设置"** 进入自建服务配置页面：

| 配置项 | 说明 |
|--------|------|
| Push Key | 自建服务的推送密钥，可点击"获取"自动填充 |
| 服务地址 | IP 或域名，支持 IPv6，不要加 http/mqtt 前缀 |
| 端口号 | 默认 3100 |
| TLS/SSL | 无证书 / 公共证书 / 自签名证书 |
| 证书内容 | 选择"自签名证书"时需要填写证书 PEM 内容 |
| 状态 | 开启/关闭 |

> 自建服务部署参考：https://github.com/yafoo/pushme-server

### 4.3 消息插件

点击 **"设置"** 进入插件管理页面，可添加、编辑、启用/禁用插件。详见 [消息插件](#11-消息插件)。

### 4.4 消息转发

点击 **"设置"** 进入转发配置页面。详见 [消息转发](#12-消息转发)。

### 4.5 消息内链接打开方式

- **系统**：使用系统浏览器打开
- **PushMe**：在 APP 内置 WebView 中打开
- **注意**：仅 Markdown 和 HTML 消息中的链接支持此设置
- 消息中可通过 `?target=blank` 或 `?target=self` 参数单独控制

### 4.6 HTML 消息 JS 支持

- **禁用**：不执行 HTML 消息中的 JavaScript
- **开启**：允许执行 HTML 消息中的 JavaScript

### 4.7 新消息默认状态

- **未读**：新收到的消息默认为未读状态
- **已读**：新收到的消息默认为已读状态

## 5. APP 设置

侧边栏 → **APP 设置**

### 5.1 APP 语言

- **选项**：系统 / 中文 / 英文
- 切换后需重启 APP 生效

### 5.2 APP 主题

- **选项**：系统 / 暗色 / 亮色

### 5.3 APP 颜色

- **系统**：跟随系统动态颜色（Material You）
- **PushMe**：使用默认主题色
- **自定义**：点击"选择颜色"按钮，通过取色器自定义主题色

### 5.4 系统最近任务

- **显示**：在最近任务列表中显示 PushMe
- **隐藏**：从最近任务列表中隐藏 PushMe

### 5.5 状态通知

状态通知用于显示 MQTT 服务的连接状态，以通知形式展示。

| 选项 | 说明 |
|------|------|
| 通知 | 始终显示状态通知 |
| 限静 | 始终显示状态通知，但在指定时间段内静音 |
| 静音 | 始终显示状态通知，始终静音 |
| 限断 | 仅在服务断开连接时显示通知 |
| 关闭 | 不显示状态通知 |

**限时静音**：选择"限静"后，可设置静音的开始和结束时间。

### 5.6 语音通知

设置收到消息时 TTS 语音播报的内容字段：
- **标题**：只播报消息标题
- **内容**：只播报消息内容
- **标题+内容**：播报标题和内容

> 语音通知需要在对应通知通道中单独开启。

### 5.7 重复通知间隔

设置重复通知的时间间隔（单位：秒），默认 30 秒。

> 重复通知需要在对应通知通道中单独开启。

### 5.8 消息通知按钮

- **显示**：通知上显示"已读"和"删除"操作按钮
- **隐藏**：不显示操作按钮

## 6. 权限设置

侧边栏 → **权限设置**

### 6.1 闹钟提醒

Android 12+ 需要闹钟权限来保证后台服务的正常运行。

### 6.2 自启动

允许 APP 在设备启动后自动运行，确保消息不丢失。

### 6.3 电池优化

将 APP 加入电池优化白名单，防止系统因省电而杀掉后台服务。

### 6.4 消息通知

授予通知权限，允许 APP 显示推送通知。

### 6.5 通知通道

管理通知通道，可配置每个通道的铃声、振动、语音等：

- **消息通知**（MainChannel）：接收消息时的通知
- **状态通知**（StateChannel）：服务连接状态通知
- **自定义通道**：消息标题中通过 `[~通道名]` 语法创建的通道

每个通道可独立配置：
- **语音通知**：开启/关闭该通道的 TTS 播报
- **重复通知**：开启/关闭该通道的重复提醒

> 提示：请开启锁屏通知，否则锁屏后可能没有声音。

## 10. 消息标题语法

消息标题支持特殊语法来提取元信息：

### 10.1 主题标记

```
[i] 信息消息      → 蓝色信息图标
[s] 成功消息      → 绿色成功图标
[w] 警告消息      → 黄色警告图标
[f] 失败消息      → 红色失败图标
```

### 10.2 频道标记

```
[~频道名] 消息标题   → 消息发送到指定通知频道
```

### 10.3 分组标记

```
[#用户名] 消息标题           → 消息归入"用户名"分组
[#用户名!头像URL] 消息标题   → 消息归入分组并设置头像
```

### 10.4 组合使用

```
[s][~我的频道][#张三!https://example.com/avatar.png] 任务完成
```

## 11. 消息插件

消息插件基于 QuickJS JavaScript 引擎，可在消息到达时对其进行预处理。

### 11.1 插件编辑

每个插件包含：
- **插件名字**：标识名称
- **插件代码**：JavaScript 代码
- **状态**：启用/禁用

### 11.2 插件输入

插件接收一个 `msg` 对象：

```javascript
msg.title    // 消息标题
msg.content  // 消息内容
msg.date     // 消息日期
msg.type     // 消息类型
```

### 11.3 插件输出

插件需返回一个修改后的消息对象：

```javascript
({
  title: msg.title,
  content: msg.content,
  date: msg.date,
  type: msg.type
})
```

### 11.4 环境变量（ENV）

插件可通过 `ENV.变量名` 访问预设的环境变量。

### 11.5 内置方法（PMF）

插件可通过 `PMF.方法名()` 调用 APP 内置方法（如加密、Base64 等）。

### 14.1 搜索

点击主页右上角搜索图标，开启搜索功能：

- **关键词搜索**：支持标题、内容、标题+内容搜索

  - **字段选择**：标题/内容/标题+内容

### 14.2 批量操作

搜索状态下可进行批量操作：
- 设为已读
- 设为未读
- 设为收藏
- 取消收藏
- 全部删除

## 16. 常见问题

### Q: 消息收不到？

1. 检查 Push Key 是否已获取
2. 检查 MQTT 服务连接状态（查看状态通知）
3. 确认权限设置（自启动、电池优化、通知权限）
4. Android 12+ 确认闹钟权限已开启
5. 尝试在消息设置中关闭 TLS 试试

### Q: 服务断开后无法重连？

- APP 使用 AlarmManager 定时重连，间隔会逐渐增大（10~60秒起步，每次增加60秒）
- 确保 APP 未被系统杀掉（开启自启动、忽略电池优化）
- 网络切换（WiFi/移动数据）时会自动重连

### Q: 如何使用自建服务器？

1. 部署 pushme-server：https://github.com/yafoo/pushme-server
2. 在消息设置 → 自建服务中填写服务器地址、端口、密钥
3. 选择 TLS 模式（无证书/公共证书/自签名证书）
4. 开启状态

### Q: 如何使用消息插件？

1. 消息设置 → 消息插件 → 设置
2. 添加新插件，填写名字和 JavaScript 代码
3. 插件代码需返回处理后的 `msg` 对象
4. 可使用 ENV 环境变量和 PMF 内置方法
